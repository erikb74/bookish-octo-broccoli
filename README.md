# Bookish Octo Broccoli

A simple web game project built with Phaser.

## Current Status

Currently displaying a "Hello World" page. This will be developed into a full Phaser game.

## How to Enable GitHub Pages

To view this page on GitHub Pages, follow these steps:

1. Go to your GitHub repository: `https://github.com/erikb74/bookish-octo-broccoli`
2. Click on **Settings** (top menu)
3. Scroll down to the **Pages** section in the left sidebar
4. Under **Source**, select the branch you want to deploy (usually `main` or `master`)
5. Keep the folder as `/ (root)`
6. Click **Save**

After a few minutes, your site will be available at:
`https://erikb74.github.io/bookish-octo-broccoli/`

## Local Development

To view the page locally, simply open `index.html` in your web browser.
